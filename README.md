# Chamada UEBS — React Native

Migração do app de chamada do fretamento universitário da UEBS para React Native (Expo), feita passo a passo no Snack.

- Snack: https://snack.expo.dev/@leonoaldebaran/26a8b7
- App web original (backup): https://github.com/leonoaldebaran-hash/ChamadaUebsOriginal
- Roteiro das tarefas: [docs/ROTEIRO_SNACK.md](docs/ROTEIRO_SNACK.md)
- Apostila de referência: [docs/React native.pdf](docs/React%20native.pdf)

## Estrutura

```
App.js                ← tela principal
package.json          ← bibliotecas (dependências)
assets/images/        ← imagens
components/<nome>/    ← componentes (pasta camelCase, arquivo PascalCase + Style.js)
docs/                 ← roteiro, apostila e mapa do app original
```
